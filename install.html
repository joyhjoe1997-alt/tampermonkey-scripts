How to install:
1. Make sure Tampermonkey is installed in your browser
2. Click "Install" on each script you want (or "Install All" for everything)
3. Tampermonkey will open a confirmation tab for each script - click "Install" there
4. Done! Scripts auto-activate on their target pages.
